# Test Cases - Bổ Sung Công Tắc Bật/Tắt Tự Động Dịch Đoạn About Me Vào Màn Hình Gemini Setting (Backend)

Tài liệu kiểm thử chi tiết cho chức năng bổ sung trường cấu hình **Auto Translate Partner Profile** trên màn hình **Gemini Setting** của Backend.

---

## I. Bảng Mô Tả & Mục Tiêu Kiểm Thử (Jira / Redmine Ticket)

| Description (Phạm vi kiểm thử) | Objective (Mục tiêu kiểm thử) |
| :--- | :--- |
| - Rà soát và kiểm thử tính năng bổ sung trường cấu hình Auto Translate Partner Profile trên màn hình cấu hình Gemini Setting của Backend.<br>- Xác thực hiển thị giao diện, vị trí, kiểu điều khiển Dropdownlist gồm 2 giá trị On và Off, giá trị mặc định Off và tính đa ngôn ngữ Anh, Nhật của trường mới cùng 2 nút điều khiển Cancel và Save.<br>- Xác thực các luồng tương tác: Thay đổi giá trị On hoặc Off và bấm Save hiển thị popup thông báo thành công Updates successfully hoặc cập nhật thành công theo common rule; thao tác bấm nút Cancel để hủy thay đổi và reset về trạng thái lưu gần nhất; hành vi khi tải lại trang F5 hoặc chuyển menu mà chưa bấm Save.<br>- Xác thực các quy tắc nghiệp vụ cốt lõi:<br>  + Khi Auto Translate Partner Profile bật On, nếu Gemini setting bật On thì hệ thống sử dụng engine Gemini để dịch đoạn About Me; nếu Gemini setting tắt Off thì hệ thống sử dụng engine Google Translation API để dịch đoạn About Me.
