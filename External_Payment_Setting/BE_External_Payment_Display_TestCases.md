# Test Cases - Cài Đặt & Điều Kiện Hiển Thị Thanh Toán Ngoài (Backend & Viewer App)

Tài liệu kiểm thử toàn diện cho tính năng **Cài đặt hiển thị thanh toán ngoài (`外部決済表示設定 / External payment setting`)**, **Cài đặt quản trị viên cho từng người dùng (`管理者設定（外部決済） / Admin setting`)** trên hệ thống Backend (BE) và **Luồng điều kiện hiển thị thanh toán ngoài** trên các ứng dụng **Viewer App** (áp dụng cho cả **chức năng mua point ở bên ngoài** và **màn hình trong cuộc gọi video / In-Video Call**).

---

## V. Các điểm cần xác nhận thêm với BA/Dev để hoàn thiện Test Case biên

1. **Mốc biên số lần mua hàng (`購入回数 / Number Of Purchases`):** Cần confirm công thức so sánh là `>=` hay `>` (ví dụ cấu hình là `3` và user đã mua đúng `3` lần) và phạm vi tính giao dịch (có tính IAP / giao dịch hủy/refund hay không) để bổ sung test case tại đúng giá trị biên trên cả **Chức năng mua point bên ngoài** và **Màn hình In-Video Call**.
2. **Tổ hợp `VPNユーザー = 表示する / Display` với user KHÔNG dùng VPN nhưng IP ngoài Nhật Bản (`TC-APP-EXTPAY-017`):** Cần xác nhận lại ý đồ BA xem user không dùng VPN có bắt buộc phải đi qua bước check IP ngoài Nhật Bản (tức kết quả phải là **Không hiển thị**) hay đúng như sơ đồ luồng hiện tại (đi thẳng tới **Hiển thị**).
3. **Cấu hình `男性身分証必須モード`:** Cần hỏi Dev/BA vị trí setting của mode này trên Backend và xác nhận có kèm điều kiện giới tính user (`Male`) hay áp dụng chung toàn app.
4. **Quy tắc validate `フィクサーアクセスキー / Fixer Access Key`:** Cần làm rõ cơ chế kiểm tra key hợp lệ (chỉ kiểm tra format/độ dài hay gọi API Fixer xác thực key hoạt động), độ dài tối đa cho phép và câu thông báo lỗi tiếng Nhật nếu có tách riêng ngôn ngữ.
5. **Cơ chế lấy cấu hình mới trên Viewer App:** Cần xác nhận App tải cấu hình thanh toán ngoài tại thời điểm nào (khi mở App/login, mỗi lần mở màn mua point/vào phòng gọi, hay real-time) để chuẩn hóa thao tác cập nhật đồng bộ trong `TC-APP-EXTPAY-021`.
