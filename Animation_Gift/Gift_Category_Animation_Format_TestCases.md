# Bộ Test Cases Chuẩn Hóa - Cấu Hình Gift Category In Video Call
## (Trọng Tâm: 2 Cột Animation APNG & WEBM/WEBP trên Backend | Kiểm Thử Chuyên Sâu App Mới & App Cũ)

Tài liệu kiểm thử được tối ưu theo yêu cầu nghiệp vụ:
- **Phân hệ Backend (OneLive BE):** Tập trung 100% vào phạm vi thay đổi của **2 cột `Animation (APNG)` và `Animation (WEBM/WEBP)`**, nút `Select`, các thao tác `Add`, `Edit`, `Cancel`, `Save`, validate dung lượng 5MB, sai định dạng, cắt ngắn tên file `...` và bảo mật magic bytes. Lược bỏ hoàn toàn các case chung không thuộc phạm vi (Point, Image, Delete, Edit order...).
- **Phân hệ Mobile App (Video Call):** **Là trọng tâm chính**, bao phủ 100% ma trận kiểm thử giữa **App Mới vs App Cũ**, thứ tự ưu tiên hiển thị, cơ chế Fallback, gọi lệch phiên bản (Cross-version Call) với file khác nội dung, hàng đợi và tương thích ngược.

## 4. Bảng Quy Tắc Nghiệp Vụ Cốt Lõi Đã Thống Nhất 100%

| Thành phần / Phân hệ | Quy tắc đặc tả chốt 100% | Hành vi hiển thị / Phản hồi của hệ thống |
| :--- | :--- | :--- |
| **Backend: Cột Animation (APNG)** | - **Bắt buộc (Required \*)**.<br>- Định dạng hợp lệ: `.apng`, `.png`.<br>- Dung lượng tối đa: **5MB**.<br>- Chọn 1 file/lần qua nút `Select APNG`. | - Bỏ trống bấm Add/Save: Báo toast `"Please select a file."`.<br>- Chọn file > 5MB: Báo lỗi dung lượng vượt quá 5MB.<br>- Chọn sai định dạng: Báo toast `"File not valid type"`. |
| **Backend: Cột Animation (WEBM/WEBP)** | - **Tùy chọn (Optional)**.<br>- Định dạng hợp lệ: `.webm`, `.webp`.<br>- Dung lượng tối đa: **5MB**.<br>- Chọn 1 file/lần qua nút `Select WEBM/WEBP`. | - Để trống: Hợp lệ, hiển thị blank.<br>- Chọn file > 5MB: Báo lỗi dung lượng vượt quá 5MB.<br>- Chọn sai định dạng: Báo toast `"File not valid type"`.<br>- Tên file dài: Tự động rút gọn và hiển thị dấu `"..."`. |
| **Backend: Thao tác Add & Edit/Save** | - Add thành công: Hiển thị popup tạo gift thành công.<br>- Edit: Click trực tiếp vào tên file để đổi file mới.<br>- Bấm Cancel: Khôi phục lại đúng tên file ban đầu. | - Hỗ trợ sửa độc lập từng file ở 2 cột.<br>- Cho phép xóa file WEBM/WEBP để đưa gift về chỉ có APNG.<br>- Chặn lưu khi xóa trắng trường APNG. |
| **Mobile App: App Version MỚI (BR02)** | - Phiên bản App tính từ thời điểm áp dụng WebM/WebP. | - **Ưu tiên hiển thị file ở cột `Animation (WEBM/WEBP)`**.<br>- Nếu cột này để trống (Gift chỉ có APNG): **Tự động Fallback phát file ở cột `Animation (APNG)`**. |
