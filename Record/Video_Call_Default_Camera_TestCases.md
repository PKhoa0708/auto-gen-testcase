# Test Cases - Default Camera Configuration in Video Calls

Tài liệu này chứa danh sách các test case chi tiết cho chức năng **Cấu hình mặc định bật/tắt camera khi Video Call** (Ticket **NVL-232**), được trình bày theo định dạng **Description** và **Objective** theo quy chuẩn của dự án.

---

## I. Quy chuẩn viết Test Case

- **Bảng Test Case 2 cột:** `Description` | `Objective`
- **Cột Description chứa:**
  - **ID / Priority**: Mã định danh test case và độ ưu tiên (`Critical`, `High`, `Medium`, `Low`).
  - **Title**: Tên test case ngắn gọn mô tả kịch bản kiểm thử.
  - **Pre-condition**: Điều kiện chuẩn bị dữ liệu/môi trường kiểm thử.
  - **Steps**: Hướng dẫn click-by-click chi tiết từng bước thao tác của tester.
- **Cột Objective chứa:**
  - **Expected Result**: Kết quả mong đợi chi tiết của từng bước thao tác tương ứng.
- **Đối tượng cụ thể:**
  - Sử dụng **Admin A** thực hiện thao tác trên Backend Dashboard.
  - Sử dụng **Viewer B** thực hiện thao tác trên ứng dụng Client.
